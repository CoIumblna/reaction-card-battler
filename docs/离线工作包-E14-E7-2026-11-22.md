## T1 · E14 指令卡（~0.5h，目标 `order_test` 27/27）

**改哪里**：`src/core/battle.gd` 的 `play_card()`。

### 只差 3 件事（现在 27 条里 21 条已绿）

1. **目标合法性校验**（在 `elif card.type == "order":` 分支里、扣费之前加）：
   - 目标必须在棋盘上（`board.position_of(target)` 非空）；
   - `kind == "damage"` → 目标必须敌方（`target.owner == "enemy"`）；
   - `kind == "shield"` / `"heal"` → 目标必须己方（`target.owner == "player"`）；
   - 非法 → `return false`（**不扣费、卡留手里**）。
2. **指令卡伤害后的死亡移除**：`damage` 分支里 `take_damage` / `_apply_aura` 之后，若 `target.hp <= 0 and not target.is_hq` → `board.remove(target)` + 日志。
3. **兼容 M1 旧目标（必做，不做 m1 smoke 会红）**：`battle_m1_smoke_test` 会传**不在棋盘上**的 M1 `enemies` 对象、以及 `player`。所以：

   ```text
   on_board = board.position_of(target) 非空
   legacy   = enemies.has(target) or target == player
   if not on_board and not legacy: return false
   if on_board: 才按 owner/kind 校验
   ```

   `unit` 分支（`_deploy_unit`）不用动。

## T2 · E7 弃牌堆 / 牌库洗回（~1.5–2h，目标 `deck_test` 18/18）

**改哪里**：`src/core/battle.gd`。

### 规则（§26 暂定方案；❓ 三个问题见 §26，先按暂定做）

1. **字段**：`var discard: Array[Card] = []`（玩家）、`var enemy_discard: Array[Card] = []`（敌方）；`setup()` 里两个都 `clear()`。
2. **打出的指令卡**：`play_card` 结算完要**两件事都做** —— `hand.erase(card)` **并且** `discard.append(card)`（漏 erase 会让 m1 的"打出的卡从手牌移除"变红）。
3. **单位卡部署**：不进弃牌堆（`_deploy_unit` 里本来就 `erase`，不用动）。
4. **失败的出牌**：不扣费、不移手牌、不进弃牌堆（靠 T1 的返回 false 路径）。
5. **手牌满 9 抽牌**：牌库照扣，抽到的那张进对应弃牌堆（不是凭空消失）。
6. **牌库抽空要抽牌**：把对应弃牌堆**洗回牌库**再抽；洗回用 `Battle.rng` 洗（`Array.shuffle()` 用全局随机数，不可复现）；弃牌堆也空 → 抽牌失败、不崩。
7. **敌方对称**：`enemy_deck` / `enemy_hand` / `enemy_discard` 同一套逻辑。

**怎么改**：把 `_draw_into()` 参数化（例如多传一个弃牌堆参数），三处调用点（`start_battle` 双方起手、`_begin_turn`、`_enemy_turn`）各传自己的弃牌堆；牌库空时先 `append_array(discard)` → `discard.clear()` → `rng` 洗牌 → 再抽。

## 常见坑速查

| 现象 | 原因 / 处理 |
|---|---|
| `SCRIPT ERROR` 后一屏红 | 脚本崩了会打断后续断言；先修崩，别数红条 |
| m1 smoke 出现「打出的卡从手牌移除」红 | E14 兼容分支没加（M1 的目标不在棋盘上 → play_card 直接 return false） |
| m1 smoke 另一条「打出的卡从手牌移除」红 | E7 只 `discard.append` 忘了 `hand.erase` |
| deck_test 报「覆盖不完整 / 实际 N 项」 | 有测试段被跳过（多半是前面的字段/前置没做），按红条提示补 |
| 洗回后结果不可复现 | 用了 `Array.shuffle()`（全局随机），要换成 `Battle.rng` |
| 改了 `.gd` 行为没变 | 先 `--import`（check.bat 会自动做） |
| 退出码 0 但有 `SCRIPT ERROR` | 假绿；`check.bat` 的 SCRIPT ERROR 列非 0 就是红 |

规格细节以 `docs/implementation-tasks.md` §25 / §26 为准；有规则拿不准就记下来，回来问教练，别改测试或数据。
