# KARDS 规则参考（事实整理，供设计时对照）

> 用途：你要做「KARDS 式」的战斗模型，这份是规则底稿。
> 来源：KARDS 官网 How to play（https://www.kards.com/how-to-play）+ 日文百科条目（https://w.atwiki.jp/aniwotawiki/pages/46846.html，2024-11 更新）。
> **这是事实整理，不是设计。** 你的游戏取哪些、砍哪些，写在 `docs/game-design.md` 里。

## 1. 资源与胜负

| 项 | 规则 |
|---|---|
| Kredit（费用） | 开局 1 点，**每回合 +1，上限 12**，回合开始回满未用点数 |
| 胜负 | 双方各有一个 **HQ（总部），防御力初始 20**；先打空对方 HQ 的获胜 |
| 起手 | 先手 4 张、后手 5 张，**可换牌一次**（mulligan） |
| 抽牌 | 每回合抽 1 张；**双方各自的第一个回合不抽牌** |
| 卡组 | 40 张（含 1 张 HQ，实质 39 张）；同名卡按稀有度放 1–4 张 |

## 2. 卡牌类型

| 类型 | 结构 |
|---|---|
| **单位（Unit）** | 部署费（左上大数字）、作战费（左上小数字）、攻击力、防御力、兵科、效果 |
| **指令（Order）** | 只有费用和效果，结算后不进战场 |

## 3. 伤害与行动

- **伤害是永久的**：单位不会在回合结束自动回血；防御力 ≤ 0 即被破坏。
- **召唤失调**：单位部署当回合不能移动/攻击（除非有「闪击 Blitz」）。
- **每回合只能"移动"或"攻击"二选一**，并且**移动/攻击都要额外支付作战费**（坦克例外：可以两者都做）。
- 单位攻击敌方单位时，双方**互相按攻击力造成伤害**（反击）；HQ 被攻击只掉 HQ 防御。

## 4. 战场（这是 KARDS 和炉石最大的不同）

```
        ┌───────────────────────────┐
        │   前线（双方共享，5 格）    │   ← 同一时间只能被一方占据
        └───────────────────────────┘
   敌方支援线（5 格，含 HQ）   我方支援线（5 格，含 HQ）
```

- 三条线，每线 5 格；支援线里永远有 HQ，所以实际可放 4 个其他单位。
- **前线独占**：对方占着前线时，你必须先清掉对方前线单位，才能把单位移进前线。
- **攻击范围**：地面单位只能攻击**相邻线**（支援线 ⇄ 前线），**不能支援线直接打对方支援线**；空军（战斗机/轰炸机）可以越线。

## 5. 兵科

| 兵科 | 特性 |
|---|---|
| 步兵 | 无特殊 |
| 坦克 | 一回合可以「移动 + 攻击」都做 |
| 炮兵 | 攻击时不受反击伤害 |
| 战斗机 | 可从自己支援线直接打对方支援线；轰炸机攻击有战斗机的线时只能打战斗机 |
| 轰炸机 | 可越线打支援线；攻击非战斗机不受反击；但自己被打时也不能反击 |

## 6. 关键词（能力）

Blitz（闪击：部署当回合可行动）、Guard（护卫：保护同线单位）、Alpine（每有其他山岳兵 +1/+1）、Ambush（伏击：防御时先手）、Deployment（部署时效果）、Destruction（被摧毁时效果）、Fury（一回合攻击两次）、Heavy Armor X（减伤 X）、Mobilize（回合开始 +1/+1，受伤后失去）、Pin（钉死：该单位本回合不能行动）、Retreat（退却：让单位退一条线或回手牌）、Smokescreen（烟幕：行动前不会被攻击）。

## 7. 和另外两个参照物的区别（帮你确认选择是对的）

| | KARDS | 七圣召唤 | 杀戮尖塔 |
|---|---|---|---|
| 类型 | 双人 CCG（有战场空间） | 双人 CCG（骰子 + 角色切换） | 单人 Roguelike 卡牌 |
| 资源 | Kredit 每回合增长 | 元素骰（随机） | 每回合 3 能量 |
| 战场 | **三线 + 前线争夺** | 角色站位（3 人） | 无 |
| 复杂度来源 | 位置 + 费用曲线 + 兵科 | 骰子随机性 + 角色切换 | 卡组构筑 + 遗物 |
| 对程序的要求 | 状态多、规则分支多（**适合练系统设计**） | 骰子/反应链 | 卡牌效果组合 |

**结论**：选 KARDS 路线 = 选「空间与费用的策略」，编程上要处理"单位位置、回合阶段、攻击范围"这些状态，恰好是最能练抽象的题材。
