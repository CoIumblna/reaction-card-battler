  所以：写 C 盘 / D 盘 / G 盘根 → `ERR_FILE_CANT_WRITE (12)`；读系统根证书库（需 Medium+）

  写 C 盘也被拒（`拒绝访问。`）。
  对照：bash / PowerShell 是 `High Mandatory Level (S-1-16-12288)`，所以它们写同一个 C 盘路径成功
  —— **这解释了为什么"权限全开却写不进去"**：不是 ACL、不是目录缺失、不是杀毒/CFA/AppContainer/IFEO，
  也不是 DSH 沙箱（用 WMI 完全脱离 bash 进程树启动 Godot，结果一模一样）。
